# Responsive Navbar

A responsive navigation bar built with React, Tailwind CSS, Vite, and Lucide icons.

## Features
- Desktop navigation links
- Mobile hamburger / close button
- Animated mobile dropdown
- Closes the menu after selecting a link
- Accessible labels and expanded state
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Publish to GitHub

Create a new empty repository on GitHub, then run these commands from this folder:

```bash
git init
git add .
git commit -m "Build responsive navbar"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/responsive-navbar.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
